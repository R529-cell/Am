1.1 Pengertian Website & Kategorinya

Website adalah kumpulan halaman digital berisi teks, animasi, gambar, suara, video, atau gabungan semuanya yang terhubung melalui internet sehingga dapat dilihat siapa pun yang terkoneksi jaringan internet.

  • Web Statis: halaman tidak berubah; perubahan dilakukan manual dengan mengedit kode struktur website.
  • Web Dinamis: disusun untuk sering diperbarui; biasanya ada halaman backend untuk mengubah konten (contoh: web portal, web berita).
  • Web Interaktif: terjadi interaksi antar pengguna, misalnya forum diskusi atau blog, dengan moderator sebagai pengatur alur diskusi.

Pemrograman Web & Bahasa Skrip

Pemrograman web adalah pembuatan aplikasi dengan bahasa skrip yang hasilnya diakses melalui web browser. Satu halaman website membutuhkan pemahaman empat bahasa skrip berikut:

2.1 – 2.2 Pengertian & Struktur Dasar HTML
HTML (Hypertext Markup Language) adalah bahasa untuk menampilkan website. Dokumen HTML berupa teks yang bisa diedit editor teks apa pun dan disimpan berekstensi .html. Elemen dibungkus tag yang diawali < dan diakhiri >.
Struktur Dasar HTML
<html>
<head>
  <title> Judul Web </title>
</head>
<body>
  Isi halaman web
</body>
</html>
Fungsi & Penjelasan Kode
  • <html>: Tag awal dan akhir dokumen HTML.
  • <head>: Tag kepala, dieksekusi lebih dulu dari body. Berisi <meta> dan <title>.
  • <meta>: Informasi/header dokumen; atribut: http-equiv, content, name.
  • <title>: Judul halaman, tampil di title bar browser.
  • <body>: Berisi konten halaman web.
2.3 Tag HTML
Tag ditulis berpasangan: tag pembuka tanpa garis miring, tag penutup dengan garis miring (/) sebelum nama. Tag tidak membedakan huruf besar/kecil, namun standarnya huruf kecil.
TagKegunaan

<body>Mendefinisikan isi sebuah dokumen
<h1>…</h1> s/d <h6>Heading 1 sampai 6, ukuran dari yang terbesar sampai terkecil
<p>…</p>Paragraf
<br>Baris baru (break line)

2.4 Tabel HTML: tr, td, th, rowspan, colspan, cellpadding, cellspacing
  • <tr> = Table Row (baris), <td> = Table Data (sel), <th> = Table Header (sel judul).
  • rowspan menggabungkan sel secara vertikal; colspan menggabungkan sel secara horizontal.
  • cellpadding = jarak isi sel ke border dalam; cellspacing = jarak antar border (satuan pixel).

PHP (PHP Hypertext Preprocessor) adalah bahasa skrip server-side yang mem-parsing kode PHP dari file berekstensi .php sehingga menghasilkan tampilan website dinamis di sisi client (browser). Dikembangkan oleh Rasmus Lerdorf pada 1995 (dirilis sebagai PHP/FI); pada 1997 perusahaan Zend mengembangkan interpreter-nya menjadi lebih baik.

5.1 – 5.2 Komponen Form & Pengolahan Data
Website dinamis butuh interaksi browser dan server (isi teks, angka, upload file) yang diwadahi FORM HTML: pendaftaran, login, transaksi, upload file, dll. Form dibuat dengan tag <form> ... </form> dengan atribut action (halaman pemroses) dan method (cara mengirim data).
  • GET mengirim data bersama URL (terlihat di address bar).
  • POST mengirim data secara terpisah (tidak tampak di URL).

<!-- metodepostproses.php -->

Fungsi & Penjelasan Kode
  • action: File tujuan yang memproses data form.
  • method: get atau post.
  • $_GET[...]: Mengambil data yang dikirim lewat URL.

4.1 – 4.2 Pernyataan Percabangan: if..else
Percabangan membuat halaman dinamis dan interaktif: JavaScript memutuskan jalur yang dieksekusi berdasarkan hasil komputasi. Ada dua pernyataan percabangan: if..else dan switch. Kondisi adalah ekspresi bernilai Boolean (true/false).
Sintaks if..else
if (kondisi)
{
  //pernyataan1 dieksekusi bila kondisi terpenuhi
}
else if (kondisi2)
{
  //pernyataan2 dieksekusi bila kondisi1 tidak terpenuhi
}
else
{
  //pernyataan3 dieksekusi bila semua kondisi tidak terpenuhi
}
Fungsi & Penjelasan Kode
  • if: Menguji kondisi pertama.
  • else if: Menguji kondisi tambahan bila yang sebelumnya salah.
  • else: Blok bila semua kondisi tidak terpenuhi.
Praktik: Percabangan IF-ELSE, Kasus Travel, Percabangan Majemuk, dan Switch
